# 版本与发布

唯一当前版本定义是tools/version.py。C#的BuildVersion.cs、安装清单、软件包文件名及当前教程由构建生成，不手工更改25处版本字符串。历史迁移白名单、基线和已发布报告不随当前版本改变。

运行 `python tools/sync_versions.py` 同步C#与HTML；编辑HTML源请改docs/templates/*.html.in。直接构建编辑器也自动同步。独立构建使用map_editor/tools/build.py；完整套件需先生成pack再suite/tools/build.py。

`python tools/check.py --level host` 运行主机检查；`--level native` 追加安装、自动导入、CubeMX真实生成/再生成与Keil编译；`--level release` 要求维护者保存的历史归档证据，并运行tools/release.py。旧release_080.py命令兼容委托当前发布门禁。

每份本次报告必须绑定实际产物哈希，失败不发布。旧报告只用于验证旧资产未变化，不给新包背书。原始Keil日志可能含许可证信息，仅留忽略的build目录。

0.8.1使用独立安装目录和foxmolika_Tools_081；重新关联时校验已知0.8.0助手哈希，切换新工具并保留旧目录。自定义工具需要手工合并，不能强制覆盖。0.8.0组件可继续供旧工程使用；升级工程请显式重新关联、Generate、Keil重载。

正式GitHub发布新建v0.8.1标签与Release，旧v0.8.0附件保持原样；上传前核对本地发布核验和SHA256SUMS，下载后可按同一清单验证。

文件操作诊断：目录重命名只对5/32/33作有限重试；原子File.Replace另处理本机复现的1175（ERROR_UNABLE_TO_REMOVE_REPLACED），每次前提是目标和暂存快照未变化。1176/1177等不盲目重试。持续拒绝仍退出，错误保留路径、次数、HRESULT及清理原因。

本次验收摘要见[release-0.8.1.json](validation/release-0.8.1.json)。最终产品主机/native检查从首步执行，资源审计因Windows PowerShell启动失败改用只读取摘要的C#工具后，仅续跑发布阶段；历史固件比较仅规范Git的CRLF/LF差异，新pack与本次源文件仍逐字节一致。
