RCS 底盘 · CubeMX 使用说明

RCS.Chassis 0.3.4：在 CubeMX 原生参数页选择麦轮或全向轮、填写尺寸，点击 Generate Code，得到独立的底盘 .c 和 .h。不需要打开离线配置器，也不需要 Python。

1 · 安装

准备 Windows x64 和已安装的 STM32CubeMX 6.18.1（其他版本尚未完成验收）。本版面向 STM32F407 HAL + M3508/C620。

  1. 保存工程并关闭 CubeMX。
  2. 运行合并安装器 RCS_CubeMX_Suite_Setup_0.3.4_win-x64.exe。安装器会自动搜索 CubeMX；找不到时点击“选择程序…”选择本机 STM32CubeMX.exe，不需要选 .pack。
  3. 选择套件保存目录（默认 LocalAppData\RCS_CubeMX_Suite_0.3.4），点击 安装 / 修复。
  4. 安装器调用 CubeMX 官方导入命令，检查注册 XML 和包内全部文件哈希；两项都通过才显示成功。

安装器还会安装地图编辑器 0.2.0、RCS_KeilHeaders.exe、示例和说明。扩展包由 CubeMX 放入其配置的 Repository/Packs/RCS/Chassis/0.3.4。安装器不修改 CubeMX 本体、汉化补丁或你的工程源码。

只拿到 RCS.Chassis.0.3.4.pack 时，也可以在 CubeMX 的 Help → Manage embedded software packages → From Local 手动导入；这样不会安装地图编辑器和 Keil 头文件工具。

2 · 选择组件

  1. 打开已有的 STM32F407 工程，或新建 F407 工程。
  2. 在 Pinout & Configuration 顶部点击 Software Packs → Select Components，展开 RCS.Chassis 0.3.4，勾选 Robotics Chassis，点 OK。
  3. 在左侧 Middleware and Software Packs → Chassis 中，再勾选上方的 Robotics Chassis 模式。下方才会显示中文“底盘参数”页。这是两个不同的勾选步骤。

3 · 填写参数

参数填写规则
底盘布局四麦轮 X 型；切向三全向轮 120°；切向四全向轮 90°。
轮子直径直径，单位 mm。
麦轮轮距前后轮中心距和左右轮中心距，均为完整距离，单位 mm。
全向轮几何底盘中心到轮中心的半径，以及 W0 位置角；各轮等角间隔、切向滚动。
减速比电机转子转速 / 实际轮子转速，包含全部传动。默认 19.2032 对应 M3508 原装减速箱（3591/187），加装外部传动时乘上外部速比。
CAN / 电机 ID全部电机共用 CAN1 或 CAN2，ID 1..4，不可重复；方向按实车确认。
PID 和限制默认 PID 为零；必须按实车调参。速度为电机端 rpm，电流限制为 C620 原始协议计数（1..16384）。
控制周期与超时默认周期 5 ms、命令超时 200 ms、反馈超时 100 ms；命令/反馈超时必须大于控制周期。

坐标 x 向前、y 向左、逆时针角速度为正。麦轮 W0/1/2/3 分别是左前、右前、左后、右后。CAN 引脚、时钟、位时序、中断仍在 CubeMX 外设页面配置；启用 CAN 的 Automatic Bus-Off Management 可在总线恢复后自动退出 bus-off。

0.3.4 会在编译时检查组合约束。重复电机 ID、超时 ≤ 周期、方向不是 ±1、电流上限越界、布局或 CAN 越界都会直接触发 #error "RCS: ..."，不再出现“生成成功但 RCS_Init 返回 0、底盘不动”。

4 · 点击 Generate Code

在 Project Manager 中选择已有的输出目录与工具链，点击右上角 Generate Code。生成结束后打开输出工程，查找下面的文件。修改轮径后再生成，rcs_config.h 中对应宏应随之改变。

生成文件作用
rcs_chassis.c / .h运动学和轮速换算
rcs_control.c / .h速度闭环、限速、超时及锁定
rcs_hal.c / .hSTM32F4 HAL CAN 适配与接口
rcs_config.hCubeMX 根据参数生成的配置头

本机验证的路径为 Middlewares/Third_Party/RCS_Robotics/RCS_Chassis/；配置头在 Inc/。如果启用了 CubeMX 的 Core 目录结构，配置头可能位于 Core/Inc/。

关于 main.c：本扩展不向 main.c 插入底盘初始化、循环或回调。CubeMX 本身仍会照常生成芯片工程的 main.c；底盘功能均保存在上面的独立文件。

5 · Keil 工程里的头文件

CubeMX 的 MDK 导出只把组件 .c 登记到工程分组，头文件只进 Include Path，因此 Keil 工程树里看不到 rcs_*.h（编译不受影响）。需要直接打开头文件时，每次 Generate Code 后运行一次安装目录里的：

RCS_KeilHeaders.exe "D:\你的工程目录"

它把 rcs_chassis.h、rcs_control.h、rcs_hal.h 和 Inc/rcs_config.h 加入 Middlewares/Chassis/Robotics/Chassis 分组；重复运行不会重复添加，首次修改前保留 *.uvprojx.rcs-backup。

6 · 由你自己的任务调用接口

把接入放在自己的底盘任务或板级模块中：

  • RCS_Init(can) 绑定已配置的 CAN，检查返回值。
  • 现有 CAN 接收分发调用 RCS_OnCanRx()。
  • 周期任务按配置周期（默认 5 ms）调用 RCS_Process()，锁定时也要调用。
  • 显式解锁用 RCS_Arm()；成功后用 RCS_SetVelocity(vx,vy,wz) 下达命令；锁定用 RCS_Lock()。
  • 状态与故障用 RCS_State() / RCS_Fault() 查询。

模块不自动创建任务，也不定义全局 HAL 接收回调。默认未解锁；命令或反馈超时后进入故障状态并停止输出，必须重新解锁并下达新命令。完整接口见 底盘接入说明（docs/接入说明.md；包内为 Documentation/README.md）。

生成代码不等于电机已经在线或参数已经整定。当前没有实车测试结果；首次上电请架空确认轮向和反馈，并从低速、小电流开始调参。

常见问题

  • 看不到 RCS.Chassis：关闭并重开 CubeMX，确认是 F407 工程，再打开 Select Components；不是只在参数搜索框中搜文件名。
  • 看不到参数：组件选择后还需在 Chassis 页面勾选 Robotics Chassis 模式。
  • 安装未确认成功：查看套件目录中的 import-pack.log、suite-error.log；确认 CubeMX 已关闭后点“安装 / 修复”重试。也可在 CubeMX 的 From Local 中选择同目录的 RCS.Chassis.0.3.4.pack 手动导入。
  • 旧工程仍使用旧版本：安装新包不会自动迁移已有 .ioc。请在 Select Components 中明确选择 0.3.4 并核对参数。
  • 卸载：关闭 CubeMX，重新运行同一个安装器，选择原套件目录并点“卸载此套工具”。只移除本安装器首次引入且未被修改的 0.3.4 包；你的地图、工程和其他版本保留。

验证边界

本版按 CubeMX 6.18.1 的原生导入、组件选择、参数修改及 Generate Code 路径验收。合并安装器在全新隔离配置/空仓库上完成安装、修复、保留既有包、拒绝被修改包和卸载验收；主机侧完成 1555 项检查、HAL 桥接、编译期配置检查和 C++ 链接检查。

ARM 完整链接、烧录和实车验证不属于本轮结果。生成日志仍可能出现 Invalid RefComponent list 诊断（本版未消除），已逐文件核验实际生成结果。安装器和二进制尚未进行代码签名。详细记录见 验证记录（docs/验证记录.md；包内为 Documentation/Validation.md）。

技术机制：ST 的 CubeMX-enhanced CMSIS-Pack，参数及代码模板随 .pack 安装；CubeMX 本体不随本安装器分发。

0.3.4：工程关联与编译修复

  1. 安装/修复套件后，在CubeMX启用RCS.Chassis并保存.ioc。
  2. 保存并关闭工程，点击安装器“关联工程…”或运行安装目录中的RCS_ProjectSetup.exe，选择该.ioc。每个工程只需关联一次。
  3. 关联会合并.extSettings以启用CAN HAL驱动，并登记工程内的生成后工具。旧RCS组件可切换至0.3.4，原文件有备份。
  4. 重新打开.ioc，Generate Code后4个头文件会自动加入Keil分组。若Keil已打开，选择重新加载工程。

生成后结果：RCS_Tools_034/headers-result.txt。RCS_KeilHeaders.exe只作手动诊断备用。关联不会替你指定CAN引脚或初始化硬件；CAN1/CAN2、波特率、滤波、接收中断仍需按实车配置。工程已有其他生成后操作时，工具会拒绝覆盖，需先合并操作。
