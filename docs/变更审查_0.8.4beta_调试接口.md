### 3.3 map_editor/firmware/rcs_can_port.c

**改动**：当统一分发器（`rcs_hw_callbacks.c`）没有被链接进来时，HAL 的 `__weak` 空函数会让收帧退化成主循环轮询；这里补一个弱定义，让中断始终能排空 FIFO。

**影响**：强定义存在时被覆盖，行为完全不变；只有“谁都没定义”时才生效。用 `__WEAK`（CMSIS）优先，回退 GCC 属性，再回退空宏。

@@ -106,6 +106,22 @@

+#else

## 4. 回归覆盖

| 覆盖点 | 用例 |
|---|---|
| 弱回调 + 强回调共存 | `test_beta_feedback.py` 的 `wrapper=0` 配置与“duplicate global callback rejected” |
| 快照刷新与清零 | `test_beta_app.py` 的 7 个场景（含硬件分支） |
| 无硬件字节基线 | `test_beta_compatibility.py`（逐文件比对 + 新增接口正向断言） |
| 生成代码排版 | `verify.py` 的 9 文件风格检查 |
| 全链路 | `check.py --level host`，exit 0 |

## 5. 审查清单

- [ ] `cycles_to_us` 用 `SystemCoreClock / 1000000`，168 MHz 下即 `cycles / 168`；非整数 MHz 时结果偏小，不会放大间隔
- [ ] `RCS_FEEDBACK_DWT` 只在 `DWT`、`CoreDebug`、`DWT_CTRL_CYCCNTENA_Msk` 都存在时为 1，主机测试自动为 0
- [ ] `RCS_CAN_RX_WEAK` 依次尝试 `__WEAK`（CMSIS）、GCC 属性、空宏，ARMCC/ARMCLANG 均可用
- [ ] 弱定义与 `rcs_hw_callbacks.c` 的强定义不会重复符号
- [ ] `g_dbg` 字段顺序稳定（调试器按序显示），新增字段追加在末尾
- [ ] `now = HAL_GetTick()` 前移 1 行后，底盘周期判断仍为 `>= RCS_PERIOD_MS`
