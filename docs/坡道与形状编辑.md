# 0.8.0 坡道执行与形状编辑

主窗口“编辑形状”：拖顶点、边中点和旋转柄。轮廓菜单有矩形、三角形、梯形、六边形和16边椭圆近似；可加点、删点、精确旋转、放大轮廓。只支持3～32点凸轮廓，无自交/孔洞。Shift取消吸附，Esc/右键/捕获丢失/缩放取消，整次拖动单次Undo。变形不移动航点或障碍，整体平移仍可携带本面对象。

实际轮廓用于包含、线段裁剪、连接、车体包络、障碍归属和净空。坡面高度为仿射直坡，支持任意平面方向；不支持曲线纵断面。接边须等高且有正宽度；角点接触不是可通行入口。越界、自交、凹陷或过窄时不能导出。

地形执行只支持沿坡轴前进或倒车，坡上不转向/横移；任务航点及到达/纠错/离开动作须在完整水平区，距坡端须覆盖车体及姿态过渡长度。内部接边自动通过，不新增任务航点。水平平台可转向，进入坡道前用量角器或显式旋转动作对齐车头。

“坡道参数”填写TransitionMm（标定过渡长度，默认250mm）、DecelerationMmS2（实测可用减速度）、LateralToleranceMm（估计横向偏离上限）、HeadingToleranceDeg、BrakeValidated、BrakeHeader和BrakeFunction。缺省参数只用于基础模型；确认制动前不能启动坡道。BrakeFunction签名 int Name(void *context, rcs_terrain_brake_request request)，CHECK返回是否就绪，HOLD返回是否接受保持请求，均非阻塞。接受不等于真实驻坡已确认。

示例terrain_brake_port.c/.h调用现有RCS速度环，不增加传感器；只有实测确认电机、驱动、回馈和供电能力后才能使用。配置头文件terrain_brake_port.h和函数FoxmolikaTerrainBrake，保持RCS_Process周期运行，使用本版robot_route_task.c/.h示例（含条件坡道保持逻辑）。这些任务侧/硬件端口是用户接入代码，生成器不会覆盖已有任务或main；必须对照合并已有任务的故障/停止分支。RCS_FAULT时禁止自动解锁；无法接受制动请求时仍保留底盘保护，并明确可能溜坡。断电/失联不能靠软件保证驻坡，需要合适驱动或机械措施。

导出平地仍3C3H；坡道为4C4H，新增rcs_terrain.c/.h，关联工程后自动登记源与头文件。rcs_nav_update仍是编码器输入和命令出口；地形引擎持有每段标定行程，按同一单调表换算水平位移，不重复乘除cos，不在接边吸附XY。过渡角是标定模型，规划Z不是实测。前视限速提前减速；制动失效、轮速明显超限、偏离走廊或采样异常会报告故障。没有独立定位硬件时不添加纠错模板；保留0.7独立观测纠错。

新轮廓和执行参数采用v6，旧v3/v4/v5仍可读取，旧编辑器不能忽略新字段。可保存未完成草稿，但导出完整校验。6↔8导出事务保留公共USER CODE；移除有用户修改的坡道文件会拒绝，避免丢代码。工程预构建检查所有模块和地图修订，不只检查route.c。

验收包含三轮型真实8文件C编译与理想编码器闭环、平台转向多航点、几何/控件事件、普通用户安装、CubeMX原生生成/再生成、Keil实际编译。仿真和编译不代表实车摩擦、制动或打滑验证。当前不实现摩擦/扭矩前馈、姿态融合、横切坡面、坡上旋转、台阶/电梯或自动寻路。
