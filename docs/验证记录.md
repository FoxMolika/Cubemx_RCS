# 0.8.1 验证记录入口

本版按层验证：底盘纯 C 核心与 HAL 桥接、动作模型/迁移、阶段状态机、三个布局的实际生成路线、崩溃子进程故障注入、工程关联/版本门槛、隔离配置单文件安装、CubeMX 原生生成及 Keil ARM 编译链接。

新增0.8验证：27项坡道生成、74项凸轮廓几何、44项控件事件、41项可选模块工程事务；三种轮型、反向、90°旋转地图及平台转向多航段的实际8文件C闭环仿真；973项地形运行时和3140项真实任务/制动端口模拟断言。真实CubeMX对平地3C3H及坡道4C4H分别生成/删分组/重生成，Keil ARM6.22编译均为0错误0警告。启动制动绑定默认不可用，不以仿真证明实车驻坡。

当前发布产物对应的通过结果、二进制哈希与边界以安装包旁 发布核验_0.8.1.json 为准。源码的 build 目录保存本地日志；包含编译许可证等信息的原始编译日志不进入源码发布包。

本次不烧录，不连接电机，不控制车辆。主机理想编码器反馈仿真不是实车；同机隔离 CubeMX 用户配置不是第二台真实电脑。
