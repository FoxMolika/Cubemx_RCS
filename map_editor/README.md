# RCS 位点地图编辑器 0.2.0

Windows 原生 CubeMX 配套编辑器：绘制场地和矩形障碍、添加/拖动/排序位点、设定朝向/目标速度/停留，结合底盘参数和编码器分辨率生成路径数据及闭环执行模块。

0.2.0 兼容底盘 0.3.1 / 0.3.2 / 0.3.3：导入 `rcs_config.h` 时读取 `RCS_COMMAND_TIMEOUT_MS`，新增“允许采样最大间隔”参数并在导出前检查其小于命令超时；导入轮向沿用 C620 转子角度约定，外接编码器需自行核对。

## 直接使用

- 安装程序：`dist/RCS_MapEditor_Setup_0.2.0_win-x64.exe`
- 便携程序：`dist/RCS_MapEditor.exe`
- 图文说明：`dist/使用说明.html`（截图内嵌，无需联网）
- 示例地图：`dist/示例路线.rcsmap.json`

运行需要 Windows .NET Framework 4.x。运行时不需要 Python、管理员权限或网络。安装器没有代码签名，不修改 CubeMX 软件、汉化文件或工程。当前绘图画布位于独立 Windows 窗口，未嵌入 CubeMX 内部。

## 操作

1. 填场地实际尺寸及车体包络半径。选择麦轮、三全向或四全向。建议导入现有 CubeMX 工程中的 `rcs_config.h`，保持底盘几何和减速比一致。
2. “＋ 位点”按行驶顺序添加点，“选择 / 拖动”移动点。右表格可编辑坐标、朝向、速度和停留。世界X向右、Y向上、正角逆时针，0°朝右。
3. “▧ 障碍”拖出矩形。自行指定可通行路线；此版不自动绕障。相切或车体安全包络冲突会拒绝导出。
4. 地图可以保存为版本化JSON；支持撤销重做、点顺序调整、缩放/平移、网格吸附和理想路线预览。
5. 选择航点，点击“航点动作…”填写动作或保留模板。详见[航点动作说明](docs/航点动作说明.md)。导出 **rcs_route.c/h、rcs_nav.c/h、rcs_actions.c/h** 六个文件。新目录或本版六文件目录允许导出，更新时保留 USER CODE；不修改main.c或IDE工程。
6. 在自己的应用目录加入三个`.c`及头文件路径；依赖现有RCS.Chassis的`rcs_chassis.c/h`。未使用CubeMX底盘扩展时可使用便携包/安装目录的sdk文件，同名实现只编译一份。
7. `examples/robot_route_task.c/h`是可选的独立任务适配示例，已用HAL接口桩编译验证。硬件采集、实际调度和真实起跑指令由应用接入，详见HTML说明。

有效计数是**电机端解码后的counts/rev**，减速比是**电机转/轮转**。AB四倍频只换算一次。传入的是逐周期原始有符号增量，按W0..W3排序，方向由导航配置翻转一次。C620角度必须在采集层按真实采样解绕累计，并拒绝陈旧/丢帧歧义；软件不替代编码器驱动。

运行默认停止。物理定位到P0并清空旧增量后，显式Reset、获取新反馈，再通过起跑指令Start。闭环根据位置和朝向误差输出车体速度，再通过原有速度环控制电机。反馈失效、采样间隔异常、编码器突跳或单段超时会锁定故障。底盘看门狗必须保留。终点发送零目标；不自动重新起跑。

编码器计数表为理想积分参考，不是按计数总量直接停车。逐点收敛停车；无轨迹平滑、自动规划、IMU/外部定位融合或动态避障。编码器打滑/累积误差和实际控制动态需要实车验证。

## 已验证

- 实际编辑器二进制：72项模型/存储/换算/导出检查。
- 三种轮型生成结果：GCC严格C99编译，理想编码器闭环仿真共49,498项断言；覆盖实际导航代码的姿态积分、位点收敛、停留、终点零速度及故障锁定。
- 航点动作：348项生命周期和实际生成C回调检查，包含取消/超时/漂移/反馈失效；编辑器检查手写保留、冲突拒绝与航点排序。
- 独立任务适配器：解锁门控、缺失反馈和命令失败处理测试。
- 实际安装器：中文及空格路径、重复安装、已安装程序自测、拒绝覆盖陌生目录、卸载保护被修改文件、保留用户文件、干净卸载。
- 实际窗口：已检查布局、拖动位点坐标与换算表同步、撤销恢复；最终导出对话框的界面确认被用户Esc停止，未继续控制窗口。最终导出逻辑已由实际EXE自测验证。
- 未进行实车测试，也未声称完成STM32目标固件链接/烧录。

详见`docs/验证记录.md`。DeepSeek并行提供了里程计/测试边界分析及代码审查候选意见；文件修改、编译和测试均由Codex本地完成。

## 源码与重新构建

`src`为C# WinForms源码，`firmware`为C99导航模板，`tests`为测试，`tools`为构建脚本。仅构建和测试需要Python、Windows.NET Framework C#编译器；C测试需要GCC。

```powershell
python tools/build.py
python tools/verify.py
python tools/test_installer.py
python tools/package.py
```

重新构建前关闭本编辑器，避免覆盖正在运行的EXE。MIT许可见`LICENSE.txt`。
