foxmolika 0.6.0 地图、动作与量角器

2026-11-15 · STM32F407 HAL / CubeMX / Keil MDK · 独立 C/H 生成

1. 安装与打开编辑器

  1. 保存并关闭 CubeMX。运行单文件 foxmolika_CubeMX_Setup_0.6.0_win-x64.exe，安装器自动寻找 CubeMX、导入内嵌软件包并核验注册，不需要手动导入 .pack，也不需要安装 Python。
  2. 目标电脑需要已有完整 STM32CubeMX；本次本机验收版本为 6.18.1。其他 CubeMX 版本没有自动视为已验收。
  3. 安装后点击安装器的启动地图编辑器。以后可运行安装目录的 foxmolika_MapEditor.exe。
  4. 默认安装目录为 %LOCALAPPDATA%\foxmolika_CubeMX_Suite_0.6.0。安装器允许选择其他目录。编辑器是与 CubeMX 配套的独立窗口，不能在 CubeMX 画布里寻找地图入口。

0.3.7、旧安装目录与旧工程不会被本次发布目录覆盖。建议复制工程后再迁移，保留能够工作的固件。

1.1 普通用户安装与“访问被拒绝”

本版保留0.5.2对发布EXE继承Low完整性标签的修复。普通用户应以Medium、非管理员运行；当前账号自己的AppData/Local通常可写。Low级别程序会被Windows禁止写入普通用户数据目录，即使文件夹DACL允许该账号写入。

正常双击本版EXE即可。若外部目录重新给文件加了Low标签，安装器会明确提示；也提供foxmolika_CubeMX_Installer_0.6.0.zip，可在正常用户目录解压后运行其中的单个EXE。压缩包是兼容的分发方式，不需要手动导入.pack。

安装前实际检查工具目录、暂存父目录、所需CubeMX仓库与注册路径的写权限；导入工作目录和临时文件在工具自己的目录，不再写CubeMX程序目录。真正不可写时会显示完整路径，可以用“浏览…”更换工具目录；若是CubeMX仓库不可写，则需在CubeMX改为当前用户可写仓库，或在确有权限需求时处理该仓库权限。安装器不自动修改ACL或改动仓库位置。

错误报告默认保存到当前用户%LOCALAPPDATA%/foxmolika/InstallerReports，失败时依次尝试临时目录及安装器旁，并在弹窗中给出实际保存路径。报告记录异常、路径和实际Windows令牌状态，不上传。不同权限实例冲突会提示先关闭已有安装器。

2. CubeMX 选择组件，并主动关联工程

  1. 打开 F407 的 .ioc，Select Components 中选择 RCS.foxmolika 0.6.0，在 foxmolika 页启用 Robotics/foxmolika 模式并配置底盘参数。
  2. 保存并关闭 .ioc。点击安装器或地图编辑器顶部绿色栏的关联工程…，主动选择该 .ioc。仅安装软件不会自动关联任何工程。
  3. 重新打开 .ioc，Generate Code，然后在 Keil 重载工程。生成后工具自动补齐底盘头文件。
  4. CAN 引脚、时钟、位时序、滤波、接收中断、启动和任务调用仍须按硬件完成。关联仅保证 HAL 依赖及文件登记，不等于已经接好电机。

关联记录在工程内，工具目录为 foxmolika_Tools_060。官方 0.3.6/0.3.7/0.4.0/0.4.1/0.5.0/0.5.1/0.5.2 生成后工具经哈希检查后可升级；旧工具保留。未知自定义生成后命令会保留并提示合并。

3. 航点流程：平移、动作、纠偏分开

平移到点 → 停稳 → 到达后动作 → 独立纠偏 → 起步前动作 → 离开验收 → 下一点

选择一个点，点航点流程…。窗口同时显示① 到达航点后与③ 离开航点前两个独立动作框，中间是② 位置纠错。两个框各有添加、编辑、上移、下移和删除按钮，不再通过下拉框切换。主窗口表格也分成“到达后”和“离开前”两列，双击任一列即可打开流程。

“到达后动作”和“起步前动作”保留原有执行顺序与数据；旋转不再依靠重叠位点表达，普通行驶只平移。取消整个流程窗口会放弃本次修改。

动作类型填写内容执行含义
绝对旋转地图目标角度、方向、限速、角加速度、容差、停稳与漂移上限XY 命令为零，仅转向
相对旋转相对动作开始时车头的角度开始时锁存目标，支持累计转角
等待秒数、超时保持底盘零命令，控制与反馈继续运行
自定义机构公共头文件、启动、完成条件、完成清理、取消清理调用夹爪/舵机/升降已有函数，必须非阻塞

纠偏设置包括关闭/位置/位置与朝向/只验收、到达半径、精调速度、超时、次数、停稳和漂移限制。平移精调与朝向精调串行；已完成的机构动作不会因纠偏重试而重放。旋转成功会更新后续目标朝向。

终点默认不执行起步前组；需要在终点执行时，勾选“终点也执行起步前动作”。通过后结束任务，不再向外发起一段行驶。

4. 地图直接显示夹角，量角器继续保留

默认开启“显示夹角”：每个有下一段路径的航点，直接显示计划车头与出发连线之间的角度弧和“顺时针/逆时针 + 度数”，不用打开量角器，也不用逐点点击。

橙色虚线代表该点动作执行后的计划出发朝向；蓝线代表航行轨迹；紫色/青色弧线及文字是两者之间的最短转头参考角。例如 P0=(600,600)、P1=(4200,1200)，P0 出发朝向为 0°时，直接显示“P0→P1 逆时针 9.46°”。

拖动位点、修改初始朝向或旋转动作会自动刷新；缩放不改变角度。已对齐显示 0.00°，终点不显示不存在的出发角，重合段不冒充 0°。选中点加粗标注，标签尽力避让节点与路径；密集时可以放大，或用工具栏“显示夹角”隐藏/恢复。

这些是计划夹角，不是实测姿态、路径拐角或动作累计转角。全向底盘可以侧向平移，非零夹角不代表路径错误；显示标注不会自动添加旋转动作，也不改变地图参数或生成的运动代码。

点击量角器，选择 A、B 位点。可查看 A→B 对 +X、+Y 的有向角，以及与水平/竖直网格线的夹角。地图 +X 向右、+Y 向上，逆时针为正。

选择动作组和插入位置，参考朝向按此前计划动作推导；也可手动输入。面板显示从参考朝向面向连线所需的相对转角。例如连线 45°、车头 90°，需要顺时针 45°。全向车的行进方向与车头方向不必一致。

生成旋转动作时选择到达后或起步前。保留位点引用时，拖动位点会重新计算方向；固定角度则保持数值。删除引用点会使校验失败。两点重合没有连线方向，不能生成“朝向连线”的动作。

5. 保存地图、导出 C/H，再编译

  1. 保存地图。旧 v1/v2 地图会迁移为 v3 并另存，原地图保留；旧机构动作映射到起步前，角度变化映射为旋转动作，停留映射为等待。
  2. 点导出 C / H，选择导出到关联工程。输出到 Application/foxmolikaRoute，自动登记路线的 3C3H 和包含目录。
  3. 在 Keil 重载工程并 Rebuild。底盘 3C4H 加路线 3C3H 仍是独立源码，不向 main.c 插入业务。
  4. 保存地图后再次修改，必须重新导出。关联导出会登记 Keil 构建前版本检查；地图改了没导出、路线配置源码被更改或地图路径失效时会阻止构建并给出提示。

状态栏显示已保存/未保存和当前版本已导出/未导出。生成的 rcs_route_revision 供核对，不代表调试器已经加载了同一份固件。请使用同一输出目录配套的 AXF 与 HEX。

重新导出会保留 USER CODE。不要修改生成区域来绕开校验。独立导出没有关联工程时，需要自行登记文件；构建前检查针对关联工程配置。

6. 崩溃日志：本地 ZIP 与恢复副本

不可恢复异常时编辑器停止业务操作，尽力记录诊断并生成本地 ZIP，报错窗口显示完整路径，可复制路径、打开文件夹或关闭。不上传、不发送邮件。

默认位置：%LOCALAPPDATA%\foxmolika\CrashReports。ZIP 包含异常堆栈、版本、运行环境与有限操作记录，不附地图、用户代码、工程、Keil 编译日志或许可证。恢复地图单独保存在本地，原文件不覆盖；下次启动可选择恢复。

打包失败时显示原始日志的实际路径；落盘全部失败则明确提示。强制结束或断电不能保证当场报告，下次启动可补收未正常结束的会话记录。自动快照之后的最后修改可能丢失。

7. 主窗口一体编辑：航点、平台、坡道与连接

0.6.0不再通过模态地形窗口编辑。地形和航点使用同一份地图、同一个保存入口和同一套撤销/重做；没有“应用地形”门槛。路线没连完时可以直接存草稿、重新打开继续编辑。

位置入口
上方米色工具栏＋平台、＋坡道、移动表面、连接、检查、立体示例、当前层、拖动时携带本面对象、显示其他层、网格吸附、显示夹角
左侧常驻页底盘参数 / 平台/坡道 / 连接；选中表面后直接编辑坐标、尺寸、高度、限速和向下厚度
中间视图页俯视编辑 / 路线侧视 / 三维预览 / 分段参考 / 检查结果
右侧航点表与属性航点顺序、所属表面下拉框、派生Z、到达后和离开前动作；下方直接编辑XY、速度、纠错，P0还能编辑初始朝向

在地面与平台之间补坡道过渡点

  1. 在左侧或右表中选中前一个航点，例如P1。用上方当前层下拉框选择上坡道；切层会保留插入位置，不会更改P1自己的归属。
  2. 点击＋航点，在俯视图中点击坡道内部。新点插在选中点之后；没有选中点时才追加到末尾。连续点击会依次插入，原有航点和动作的稳定ID保留。右下角“追加航点”可明确切到末尾追加。
  3. 新建坡道点自动归属当前坡道，规划Z由表面和XY推导，纠错默认关闭且没有动作。已有点改归属不会静默删除动作，请按检查提示在属性或“航点流程…”中修正。
  4. 在左侧连接页的两个下拉框选表面，添加地面↔上坡道、上坡道↔平台、平台↔下坡道、下坡道↔地面。每段最多跨一次接合：地面点→上坡道点→平台点→下坡道点→地面点。
  5. 连接允许先记入草稿；未等高接边时标注“⚠ 未接合”，检查仍会报错，不会因为点过“添加连接”就视为可通行。不要直接连接不同高度的地面与平台来绕过坡道。
  6. 点击检查切到完整问题列表；双击含P编号的问题可定位相关航点。检查结果不会阻挡继续编辑和保存。

拖动与精调

在俯视编辑中直接拖动航点、障碍，或点击移动表面后拖动平台/坡道色块。这个“移动表面”入口对应旧版的“拖动表面”，新版本直接放在主窗口。重叠表面先从左侧列表选择目标；地面固定。普通选择模式下点击其他层的可见航点会选中并切换到该层；重叠航点优先当前层。

默认网格吸附；拖动表面时按住Shift临时取消吸附。拖动时携带本面对象控制本面航点/障碍是否一起平移，保留坡道局部位置和规划高度；不移动相邻连接面。原“携带本面航点/障碍”功能保留，精调表面XY仍只改表面几何。Esc / 右键 / 捕获丢失还原未完成拖动；一次完整拖动对应一次全局撤销。

坐标、尺寸与高度在左侧属性精调；航点XY、速度、纠错在右下属性精调。更换表面归属后Z立即更新。删除仍被航点、障碍或连接引用的表面会提示先处理引用。三维视图拖动用于旋转视角，侧视图显示累计水平距离与规划高度，不会在侧视图移动地形。

保存草稿和导出是两回事

点击保存草稿或Ctrl+S，未连接、临时断开的接边、路线冲突都可以保留；重新打开仍显示待修正问题。结构错误、非有限坐标和零尺寸等不能安全编辑的数据会被拒绝。所有主窗口修改共用撤销/重做（Ctrl+Z / Ctrl+Y）；选择输入框时保留其自身编辑快捷键。

三视图共享同一地图，切换视图不需要应用或关闭窗口；恢复/撤销后会重新绑定当前数据。立体地图使用v4，原有v3平地格式继续支持；首次增加地形才升级到v4。不要用旧编辑器打开v4地图。

本版仍不生成坡道控制固件。保存草稿不代表路线通过验收；导出C/H和动态预览继续严格检查，非平面路线会明确拒绝导出。含坡道/高台路线只做几何编辑、预览和检查，不会忽略Z输出平地控制。没有实测高度闭环、IMU融合、自动寻路、台阶或升降平台控制；能力限制须按真实硬件填写。

8. 接入与验证边界

任务侧使用 rcs_route_init/reset/update/start 或示例 robot_route_task.c/.h，持续调用底盘控制周期。必须提供真实时间与全部在用轮的新鲜编码器增量；生成器不自动配置编码器硬件、解绕原始角度或替代 CAN 板级接入。

轮速 PID 初值仍需调参。编码器纠偏修正的是估计坐标，不能自动识别全部打滑误差；实车旋转中心还取决于轮速跟随、安装几何与接地状态。软件测试、ARM 编译和实车验收分开记录。
