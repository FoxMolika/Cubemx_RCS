# foxmolika CubeMX 套件 0.5.0

新增平台/直坡道/多层地图编辑、俯视/侧视/三维几何预览与通行检查。航点流程改为“到达航点后”和“离开航点前”两个同时可见的独立动作框，中间独立配置位置纠错。原0.4.1保留，平地运动固件不变。

**立体地图首版不含坡道控制。** 含坡道/高台的路线明确拒绝C/H导出与平地动态预览。地面路线继续使用现有固件。没有高度闭环、IMU融合、自动寻路、台阶或升降平台控制；三维画面为规划几何预览。

STM32F407 HAL 底盘模块与位点地图编辑器。独立生成 C/H，支持 CubeMX 软件包和 Keil 工程关联，不向 main.c 插入业务。

航点执行顺序：平移到点 → 停稳 → 到达后动作 → 独立纠偏 → 起步前动作 → 离开验收。旋转是独立动作，旋转时 XY 命令为零，机构动作不会因纠偏重放。

量角器支持画布两点、网格方向与夹角、计划/手动参考朝向、相对转角、位点引用或固定角度，以及添加旋转动作。编辑器不可恢复异常生成本地 ZIP，窗口显示完整路径；恢复地图单独保存，不上传。

安装后点击“启动地图编辑器”，以后运行安装目录的 foxmolika_MapEditor.exe。要自动登记 C/H，必须主动点“关联工程…”选择已保存的 .ioc，然后 Generate Code。地图保存后还必须导出到关联工程；保存与导出不是同一个操作。

立体编辑入口在主窗口米色栏“立体地形…”，也可点“立体示例”。在地形窗口设置表面、通行连接、航点和障碍归属；Z由表面推导。主窗口“当前编辑表面”决定加点/拖动所在层。地形应用后需保存地图。

旧v1/v2迁移为v3；v3平地地图继续保持格式，应用地形后保存为v4，旧编辑器不能打开v4。建议另存地图并使用工程副本升级。只有编码器时的纠偏仍受里程计误差影响。

重建需要 Windows、.NET Framework C# 编译器、Python、GCC；原生验收另需 STM32CubeMX/F4 固件包和可用 Keil 编译器。目标电脑运行安装器/编辑器不需要 Python。查看 tools/release_050.py。
